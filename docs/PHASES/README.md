# Phase Evidence Directory

Store authoritative phase-specific reports and supporting artifacts here or link to their existing repository locations.

Suggested naming:

- Phase 2 report
- Phase 3 report
- Phase 4 report
- Phase 5A report
- Phase 6 report
- Phase 7 report

Rules:

1. One authoritative human-readable Markdown report per phase.
2. Preserve historical baselines.
3. Supporting JSON artifacts may accompany the report.
4. Do not create multiple competing "final" reports for the same phase.
5. A new phase should reference previous authoritative reports rather than duplicating them.
